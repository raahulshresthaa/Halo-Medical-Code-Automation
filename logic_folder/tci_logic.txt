This is the Logic document for TCI insoles price coding.
Be sure to write out all of your working out

Modelling 

If there is a pair then do x2 of the codes for the modelling section. (i.e. B54c x2)
If base is Carbon Fibre add code : B54a
If base is polypropylene add code : B54b
If base is 35/20/80 SH, 45/30/80 SH, 40 Shore, 50 Shore or 65 Shore then add code B54c

Modification 

Add BNS45 for all of the following (not for postings) 
for both the left and right foot modifications : 
Cut out and additions - BNS45
1st Met Head - BNS45
1st Met Ray - BNS45
5th Met Ray - BNS45
Navicular Sweet Spot - BNS45
Fascial Accommodation - BNS45
Heel Flange - BNS45
if these are on both feet just put BNS45 x2,

Postings 

Make sure that if nothing is ticked then you do not charge for rear foot and fore foot
Add B56 for Rearfoot 
Add B56 for Forefoot.

Additions

The following is a list of all the additions that can be made, if the specified addition is present add the following codes.
Valgus Pad - B41
Metatarsal Pad - B41
Metatarsal Bar - B41
Morton's Extension - B56
Reverse Morton's Extension - B56
Neurological Footplate - D8a
Balance Pad - B41
Heel Pad - B41
Cuboid Pad - B41 
Kinetic Wedge - B43
Cobra Pad - B41
Neuroma Pad - B41 
Sulcus Crest - B41
Poron Forefoot - B56
Arch Fill - B41
Heel Raise - B43
Rigid 1st Extension - B20
Recess - BNS45
Hole & Plug - BNS45
Partial Toe Block - B50
Full Toe Block - B51

Top Cover (coverings) and Linings (charged with the same code)

If there is a pair of insoles then make sure there's two codes (i.e. b55c x2)
The default code is b55a 
If the top cover is spenco the code is b55b (b55c if there is a lining)
If the base is 35/20/80 SH or 45/30/80 SH b55b(b55c if top cover is spenco or if there is a lining (or both))
if there is a lining and not the previous two options then it is b55b
if there is no coverings selected assume there is one and therefore a B55a code (B55a x2 for a pair)
