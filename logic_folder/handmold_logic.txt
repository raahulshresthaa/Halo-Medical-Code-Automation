This is the Logic document for Hand mould insoles price coding.
Be sure to write out all of your working out

Modelling 

If there is a pair then do x2 of the codes for the modelling section. (i.e. B54c x2)
If base is Carbon Fibre add code : B54a
If base is polypropylene add code : B54b
If base is 35/20/80 SH, 45/30/80 SH, 40 Shore, 50 Shore or 65 Shore then add code B54c

Modification 

Add BNS45 for all of the following (not for postings) 
for both the left and right foot modifications : 
Cut out and additions - BNS45
1st Met Head - BNS45
1st Met Ray - BNS45
5th Met Ray - BNS45
Navicular Sweet Spot - BNS45
Fascial Accommodation - BNS45
Heel Flange - BNS45
if these are on both feet just put BNS45 x2,

Postings 

Make sure that if nothing is ticked then you do not charge for rear foot and fore foot
Add B56 for Rearfoot 
Add B56 for Forefoot.

Top Cover (coverings) and Linings (charged with the same code)

If there is a pair of insoles then make sure there's two codes (i.e. b55c x2)
note that spenco counts as two coverings and that if the base is 35/40/80 SH or 45/30/80 SH then we charge for an extra covering. And that any linings (to shell, to sulcus, full) count as 1 extra covering
if you consider linings x and covers x how many x do you have, then consider x the number of covers and use that to work out the codes
1 covering - B55a
2 covering - B55b
3 covering or more - B55c
(so that 2 covering B55b, then add x2 if it is a pair so : B55b x2)
note that lining thickness does not denote a new different lining, its a description of the same one 
if there is no coverings selected assume there is one and therefore a B55a code (B55a x2 for a pair)

Please put a note at the end with the final codes saying "This Hand mould has been coded as a TCI"
